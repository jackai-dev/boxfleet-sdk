# boxfleet MCP knowledge server

Read-only stdio [MCP](https://modelcontextprotocol.io) server generated by
OmniWrap. It answers knowledge queries about the API from the bundled
`library-ir.json` and the semantic contract `semantic-api.json` and never executes target code or network
requests.

Server name (the key under `mcpServers` in `mcp.json`): `boxfleet-knowledge`

## Launch

```
python server.py
```

`mcp.json` beside this file is the canonical client configuration. It launches
`server.py` relative to the working directory; the generated `mcp.json` pins `cwd` to the published location. On macOS and Linux the
Python launcher is usually `python3`; replace `"command": "python"` with
`"command": "python3"` in the snippets below when `python` is not on `PATH`.

## Register with Claude Desktop

Add to `claude_desktop_config.json` (macOS:
`~/Library/Application Support/Claude/claude_desktop_config.json`, Windows:
`%APPDATA%\Claude\claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "boxfleet-knowledge": {
      "command": "python",
      "args": ["server.py"],
      "cwd": "C:\\Users\\jacqu\\.gemini\\antigravity-cli\\brain\\5e8ac997-1f11-49fe-b45b-e4ed82442af3\\scratch\\boxfleet-sdk\\mcp\\boxfleet-mcp"
    }
  }
}
```

## Register with Codex

Add to `~/.codex/config.toml`:

```toml
[mcp_servers.boxfleet-knowledge]
command = "python"
args = ["server.py"]
cwd = "C:\\Users\\jacqu\\.gemini\\antigravity-cli\\brain\\5e8ac997-1f11-49fe-b45b-e4ed82442af3\\scratch\\boxfleet-sdk\\mcp\\boxfleet-mcp"
```

Replace `C:\\Users\\jacqu\\.gemini\\antigravity-cli\\brain\\5e8ac997-1f11-49fe-b45b-e4ed82442af3\\scratch\\boxfleet-sdk\\mcp\\boxfleet-mcp` with the absolute path of this directory if the bundle
was moved or copied.
