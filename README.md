# BoxFleet SDK Suite (`boxfleet` / `boxfleek` — `@jackai-dev/boxfleet-sdk`)

Official multi-language SDKs, Agent Skill, and MCP Knowledge Server for **BoxFleet** (`boxfleet` / `boxfleek` / `jackai-box`), generated by **OmniWrap** from [`openapi/boxfleet.openapi.yaml`](openapi/boxfleet.openapi.yaml) and prepared/verified inside **E2B Firecracker MicroVMs** via BoxFleet.

- **Organization**: [`https://github.com/orgs/jackai-dev`](https://github.com/orgs/jackai-dev)
- **Repository**: [`https://github.com/jackai-dev/boxfleet-sdk`](https://github.com/jackai-dev/boxfleet-sdk)
- **Production Control Plane**: [`https://boxfleet.io`](https://boxfleet.io)
- **Generator**: **OmniWrap 2.0.0** (`omniwrap.sdk create --input-kind openapi --mode http_client --complete`)

## Quick Start

### TypeScript / JavaScript (`boxfleet-sdk`)

```ts
import { Client } from './sdk/typescript/boxfleet-sdk/index.mjs';

const client = new Client({
  baseURL: 'https://boxfleet.io',
  apiKey: process.env.BOXFLEET_API_KEY,
});

// 1. Inspect BoxFleet White-Label Zero-Idle-Cost Cloud Catalog
const catalog = await client.cloud.getWhiteLabelCloudCatalog();
console.log(catalog.zeroIdleCostModel);

// 2. Provision an instant 4 vCPU / 8 GiB Universal Linux MicroVM ($0/hr when suspended)
const { box } = await client.cloud.createCloudBox({
  body: {
    templateId: 'boxfleet-universal',
    backend: 'fly-machines',
    autoSuspendSeconds: 1800,
    vault: true,
  },
});
console.log('Box ID:', box.boxId, 'Preview URL:', box.previewUrlPattern);

// 3. Start an isolated project test or autonomous coding job
const job = await client.jobs.startProjectJob({
  body: {
    projectRoot: '/workspace/app',
    provider: 'e2b',
    action: 'test',
    install: true,
  },
});
```

### Python (`boxfleet_sdk`)

```python
from boxfleet_sdk import Client

client = Client(base_url="https://boxfleet.io", api_key="bf_live_...")

# Inspect White-Label Cloud Catalog
catalog = client.get_white_label_cloud_catalog()

# Provision a BoxFleet Cloud VM
box = client.create_cloud_box(body={
    "templateId": "boxfleet-desktop",
    "backend": "e2b",
    "vault": True,
})
print(box["box"]["boxId"], box["box"].get("desktopStreamUrl"))
```
